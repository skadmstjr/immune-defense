# 면역 디펜스

몸속에 침입한 병원체를 면역세포로 막아내는 생명과학 교육용 웹 디펜스 게임이다.

- 1차 방어선(피부·점막·분비물·섬모)을 깔고, 대식세포·비만세포·T림프구·B림프구·NK세포를 혈관에서 출동시킨다.
- 처음 보는 병원체는 정체를 알 수 없다. 대식세포가 먹어서 항원을 제시해야 정체가 드러나고 적응 면역이 열린다.
- 세균(편모 회피, 협막, 세포 내 기생, 독소), 바이러스(빠른 전파, MHC 숨김, 항원 변이), 꽃가루(감작과 알레르기)가 저마다 다른 생물학적 특성으로 움직인다.
- 피버 타임에는 체온에 따라 버프와 디버프가 갈린다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있다. 별도 설치나 서버가 필요 없다.
